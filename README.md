# 生日駭客驚喜 🎂

手機優先的生日闖關網頁，使用原生 HTML、CSS、JavaScript。無需安裝套件、無需建置，素材全部內建，不依賴外部圖片或字型服務。

## 用 VS Code 開啟

1. 解壓縮完整專案。
2. VS Code →「檔案」→「開啟資料夾」，選擇 `birthday-hack`。
3. 直接以瀏覽器開啟 `index.html` 即可遊玩；也能用 VS Code 的 Live Server 擴充功能預覽。

## 上傳 GitHub 並發布

1. 登入 GitHub，建立新的公開儲存庫，例如 `birthday-surprise`。
2. 選擇上傳現有檔案（uploading an existing file／Add file → Upload files）。
3. 將 `index.html`、`style.css`、`script.js`、`README.md` 與 `.nojekyll` 放在儲存庫最上層並提交。不要只上傳 ZIP，也不要多包一層資料夾。`.nojekyll` 是空檔，若上傳介面不接受，可省略，本專案仍能使用。
4. 到儲存庫 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**，資料夾選 **/(root)**，按 Save。
5. 等 GitHub Pages 完成部署後，使用 Pages 頁面顯示的網址。通常為 `https://你的帳號.github.io/birthday-surprise/`。
6. 把這個網址傳給朋友，手機即可開啟。公開儲存庫的程式碼與網站都能被其他人看到，祝福內容避免放私人資料。

## 互動流程

- 開場：駭客風格惡作劇彈窗，按「開始回答」。
- 第一題：20 會答錯並晃動；18 顯示「因為你永遠 18 歲」，按繼續進入下一題。
- 第二題：「我」答對；「小孤獨」前三次點擊會在整個可見畫面移動並逐次縮小，第四次消失，出現大哭表情與「選我選我選我」。仍需選「我」才過關。
- 第三題：「生日」直接進入祝福；「萬聖節」顯示萬聖節快樂及提示，保留生日按鈕。
- 結尾：生日彩帶、點蠟燭許願、切蛋糕、吃蛋糕、禮物、重新遊玩。
- 答錯一定會有畫面晃動；實體震動視手機瀏覽器支援而定，iPhone Safari 通常不支援震動 API。
- 尊重系統「減少動態效果」設定，開啟後減少動畫及震動。

## 修改祝福

在 `script.js` 最上方修改 `BIRTHDAY_MESSAGE`。在 `style.css` 修改顏色與樣式；在 `script.js` 修改題目與互動文案。

這是純前端的生日惡作劇，沒有真的控制手機，不要求麥克風、相機或個人資料。吹蠟燭以點擊完成。

目前版本：全黑背景，開場為舊式 Windows 系統彈窗；題目只有大字及方框按鈕，無進度條或裝飾介面。

## 圖片互動版結尾

- 蛋糕上方顯示「祝ㄖㄗ生日快樂!!!」，搭配提供的小孤獨圖片。
- 點蠟燭或蛋糕：吹熄燭火（點擊操作，不使用麥克風）。
- 再點蛋糕：播放切蛋糕動畫、出現切片。
- 點切片三次：逐口吃完。吃完後可點主蛋糕再取一塊。
- 點左右氣球：氣球爆開並灑下彩帶，稍後重新出現。
- 上傳 GitHub 時務必一起上傳整個 `assets` 資料夾。
